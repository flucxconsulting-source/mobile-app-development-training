# Mobile App Development Training

This repository tracks practical mobile application development training from fundamentals to production-quality Android applications.

The initial focus is Android development with Kotlin, Jetpack Compose, Gradle, Git, and GitHub. The repository is organized so each lesson or exercise can grow into working code, documentation, and reviewable commits.

## Training Goals

- Build confidence with Kotlin and Android fundamentals.
- Learn Jetpack Compose through small, working apps.
- Practice professional Git and GitHub workflows.
- Document setup decisions, debugging notes, and lessons learned.
- Progress gradually toward production-quality app structure, testing, and release practices.

## Repository Map

- `docs/` - setup guides, workflow notes, and technical explanations.
- `exercises/` - small focused practice tasks for learning individual concepts.
- `projects/` - larger app projects that combine multiple concepts.
- `resources/` - links, references, and reusable study material.
- `progress/` - learning log, covered concepts, and next steps.

## Suggested Learning Path

1. Environment setup: Android Studio, IntelliJ IDEA, Git, GitHub, Android SDK, emulator or device.
2. Kotlin fundamentals: variables, functions, classes, null safety, collections, and simple tests.
3. Android basics: project structure, Gradle, activity lifecycle, resources, and logging.
4. Jetpack Compose basics: composables, state, layout, Material design, previews.
5. App architecture: ViewModel, UI state, navigation, repository pattern.
6. Data: local persistence, preferences, files, Room, and network APIs.
7. Quality: debugging, testing, accessibility, performance, and CI.
8. Production readiness: release builds, signing, privacy, analytics, and store preparation.

## Working Agreement

- GitHub is the source of truth for code.
- Existing content should be preserved unless a change is intentional.
- Every meaningful change should have a clear commit message.
- README files should explain what each folder is for.
- Exercises should teach both the manual learning path and the professional workflow.
