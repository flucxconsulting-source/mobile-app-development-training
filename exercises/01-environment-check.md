# Exercise 01: Environment Check

## Goal

Confirm that Android Studio, Git, GitHub, and the Android runtime environment are ready for training.

## Manual Learning Path

1. Open Android Studio.
2. Create a new Android project using Kotlin and Jetpack Compose.
3. Run the default app on an emulator or physical Android device.
4. Open a terminal and check Git:

```powershell
git --version
git config --global user.name
git config --global user.email
```

5. Write down what worked and what failed in `progress/learning-log.md`.

## Professional Method

After the manual check works, create a small setup validation project and commit it to GitHub with a clear README. This proves the toolchain works end to end.

## Completion Criteria

- A Compose app runs on a device or emulator.
- Git identity is configured.
- A note is added to the learning log.
- Any setup issue is documented with cause and fix.
