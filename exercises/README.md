# Exercises

This folder is for small, focused practice tasks.

Each exercise should include:

- A short goal.
- What to type or do manually for learning.
- An optional professional or automated approach.
- Notes about common mistakes.

Suggested early exercises:

1. Validate Android Studio setup.
2. Create a Kotlin console project in IntelliJ IDEA.
3. Build a first Jetpack Compose screen.
4. Practice Compose state with a counter.
5. Debug a Gradle sync error.
