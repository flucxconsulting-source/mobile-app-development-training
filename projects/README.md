# Projects

This folder is for larger apps that combine multiple concepts.

Each project should have its own folder and README. Project folders should explain:

- What the app does.
- Which concepts it teaches.
- How to run it.
- What has been completed.
- What to improve next.

Suggested project sequence:

1. `hello-compose/` - first Compose app and project anatomy.
2. `bmi-calculator/` - inputs, state, layout, and simple logic.
3. `habit-tracker/` - lists, navigation, and local persistence.
4. `weather-client/` - API calls, loading states, and error handling.
5. `production-template/` - architecture, testing, CI, release preparation.
